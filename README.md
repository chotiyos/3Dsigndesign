# JJDesign

เว็บออกแบบป้ายตัวอักษร 3 มิติ พิมพ์ข้อความไทยหรืออังกฤษ นำเข้า SVG หรือรูปโลโก้ เลือกจาก 51 แบบ
แล้วส่งออกไฟล์ผลิต STL และ DXF หน่วยมิลลิเมตร ทุกอย่างทำงานในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์

## หน้าในเว็บ

| เส้นทาง | หน้า |
| --- | --- |
| `/` | หน้าแรกแบบแคตตาล็อก พิมพ์ชื่อร้านแล้วเห็นป้าย 3D แยกชิ้นทันที |
| `/app` | ตัวออกแบบ 4 ขั้น: ข้อความหรือรูป → เลือกแบบ → ปรับขนาด → ส่งออก |
| `/styles`, `/styles/:id` | แคตตาล็อก 51 แบบ และใบสเปกของแต่ละแบบ |
| `/files` | ไฟล์ 3D สำเร็จรูป |
| `/lightbox` | กล่องไฟจากรูป แยกสีเป็นชั้นพิมพ์ 3D หลายสี พร้อมกรอบ ฝาหลัง และที่ยึด |
| `/gen` | หน้าโมเดลจาก AI (ใช้โมเดลตัวอย่าง ยังไม่ต่อบริการ AI) |
| `/how-to`, `/plugin`, `/contact`, `/terms`, `/privacy`, `/login`, `/account` | หน้าข้อมูลและบัญชีทดลอง |

## แบบป้าย 51 แบบ

แบ่งเป็น 7 หมวด อยู่ใน `src/lib/styles/`:
A ป้ายไฟตัวอักษร (16) · B อักษรพิมพ์ทั้งตัว (3) · C ป้ายตั้งโต๊ะ (3) · D กล่องไฟและถาด (5) ·
E อักษรตกแต่ง (6) · F ของที่ระลึก (6) · G อุปกรณ์และอะไหล่ (12)

ทุกแบบคำนวณจากรูปทรง 2 มิติหน่วยมิลลิเมตร (`src/lib/geo2d.ts`, Clipper) แล้วยกเป็นชิ้น 3 มิติ (`src/lib/solid.ts`)
แกน Z = 0 คือด้านหลังป้าย ค่าบวกชี้ออกด้านหน้า

## สิ่งที่ยังเป็นตัวอย่าง (ต้องแก้ก่อนเปิดใช้จริง)

- บัญชีและเครดิตทดลอง เก็บใน localStorage ของเบราว์เซอร์เท่านั้น ไม่มีการเก็บเงินจริง
- ไฟล์สำเร็จรูปอยู่ใน `src/data/shop.ts` ค่าเครดิตต่อการดาวน์โหลดอยู่ใน `src/lib/account.ts`
- ข้อมูลติดต่อในหน้า `/contact` ยังว่าง
- หน้า AI ใช้โมเดลตัวอย่าง ปลั๊กอิน Illustrator/CorelDRAW ยังไม่ได้ทำ
- เงื่อนไขการใช้งานและนโยบายความเป็นส่วนตัวเป็นฉบับร่าง

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ทดสอบรูปทรงทุกแบบ การส่งออกไฟล์ และระบบสาธิต
npm run build    # สร้างไฟล์เว็บใน dist/
```

เว็บเป็น single-page app ถ้าเอาขึ้น hosting แบบ static ต้องตั้งให้ทุกเส้นทางส่ง `index.html`
(ใน Cloudflare Pages ใช้ไฟล์ `public/_redirects` ที่มีให้แล้ว)

ฟอนต์ในโฟลเดอร์ `public/fonts` เป็นฟอนต์ SIL Open Font License จาก Google Fonts
